# 🌐 My Personal Portfolio

Welcome to my personal portfolio repository! 👋

This project showcases my technical skills, projects, and development journey as a Computer Science Engineering graduate aspiring to become a **Python Developer**.

## ✨ About the Project

My Portfolio is a personal website created to present my profile, technical skills, projects, and resume in one place. It provides visitors with an overview of my background and the projects I have developed.

## 🚀 Features

- 👩‍💻 Personal introduction and profile
- 🛠️ Technical skills showcase
- 💼 Projects section with project descriptions
- 📄 Resume resources
- 🖼️ Images and visual assets
- 📱 Website styling with CSS
- ⚡ JavaScript for interactive functionality

## 🧰 Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactive website functionality

## 💻 Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the repository

```bash
git clone https://github.com/saniyachandane/My-Portfolio.git
```

### 2. Navigate to the project folder

```bash
cd My-Portfolio
```

### 3. Open the website

Open `index.html` in your preferred web browser.

You can also open the project in Visual Studio Code and use Live Server for local development.
